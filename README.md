# Artsy Cafe

**Sitio web para una cafetería | Diseño web y desarrollo frontend**

Tierra Café es un proyecto web diseñado para transmitir la esencia de una cafetería mediante una interfaz moderna, cálida y visualmente atractiva. El sitio permite presentar la marca, mostrar sus productos, dar a conocer al equipo de trabajo y facilitar la comunicación con los clientes.

## ✨ Características

- **Página de inicio:** presentación visual de la cafetería.
- **Sección Nosotros:** información sobre la identidad y esencia de la marca.
- **Catálogo de productos:** tarjetas con imágenes, nombres y precios.
- **Nuestro equipo:** presentación del personal de la cafetería.
- **Formulario de contacto:** espacio para consultas y mensajes.
- **Redes sociales:** enlaces para conectar con la cafetería.
- **Diseño responsive:** adaptación a diferentes tamaños de pantalla.
- **Detalles visuales:** iconografía, efectos hover y separadores decorativos con ondas SVG.

## 🛠️ Tecnologías utilizadas

- HTML5
- CSS3
- Boxicons
- SVG

## 🎨 Diseño

La interfaz utiliza una paleta de colores inspirada en el mundo del café, combinando tonos azules, marfil y naranja para lograr una apariencia equilibrada y acogedora.

El diseño prioriza la legibilidad, la organización del contenido y una experiencia de navegación sencilla.
